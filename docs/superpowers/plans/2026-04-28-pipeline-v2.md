# Pipeline V2: Chunk-Collect Architecture + bigWig Reader Optimizations

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the channel+BTreeMap pipeline with chunk-based rayon ordered collect, add proper output-path dispatch based on sortRegions semantics, eliminate unnecessary allocations in the bigWig reader, and fix the BedRecord double-clone.

**Architecture:** The current `execute_mode` uses a `sync_channel(256)` + writer thread + BTreeMap reordering for all code paths. This is replaced by a simpler architecture: rayon chunk-parallel ordered collect as the unified compute layer, with output dispatch split into three paths — streaming (keep+sorted / no), group-bucket in-memory (ascend/descend), and fallback in-memory (keep+not-sorted). The bigWig reader gains buffer reuse for `values()`, `search_cir_tree()`, and the zlib decompression path. BedRecord construction switches from `Arc::new(record.clone())` to consuming `groups` via `into_iter()`.

**Tech Stack:** Rust, rayon (ordered parallel collect), flate2/zlib-rs, std::sync::mpsc (removed)

**deepTools compatibility notes:**
- `sortRegions=keep` (default): output must match input BED region order
- `sortRegions=no`: output order is non-deterministic in deepTools (mapReduce shuffles tasks); our implementation may output in compute order — this is acceptable
- `sortRegions=ascend/descend`: rows sorted by signal metric within each group; tie-breaking order does not need to match deepTools

```rust
pub struct GroupBucketCollector {
    buckets: Vec<Vec<MatrixRow>>,
    sample_count: usize,
    bin_count: usize,
}

impl GroupBucketCollector {
    pub fn new(group_count: usize, sample_count: usize, bin_count: usize) -> Self {
        Self {
            buckets: (0..group_count).map(|_| Vec::new()).collect(),
            sample_count,
            bin_count,
        }
    }

    pub fn on_row_with_group(&mut self, group_index: usize, row: MatrixRow) -> Result<()> {
        self.buckets[group_index].push(row);
        Ok(())
    }

    pub fn finalize_grouped<F>(self, header_builder: F) -> Result<MatrixData>
    where
        F: FnOnce(Vec<usize>) -> Result<MatrixHeader>,
    {
        let group_counts: Vec<usize> = self.buckets.iter().map(|b| b.len()).collect();
        let total_rows: usize = group_counts.iter().sum();
        let mut rows = Vec::with_capacity(total_rows);
        for bucket in self.buckets {
            rows.extend(bucket);
        }
        let header = header_builder(group_counts)?;
        Ok(MatrixData {
            header,
            rows,
            bin_count: self.bin_count,
            sample_count: self.sample_count,
        })
    }
}
```

```rust
enum OutputStrategy {
    /// keep + input sorted, or sortRegions=no: streaming via FileCollector.
    /// Chunks are written to the collector immediately after compute.
    StreamOrdered,
    /// keep + input NOT sorted: fall back to in-memory collect, then sort by orig_idx.
    InMemoryKeep,
    /// ascend/descend: collect into group buckets, sort within groups later.
    InMemoryGroupBucket,
}
```

- [ ] **Step 2: Rewrite `execute_mode` body**

The generic bounds on `C` and `F` no longer need `Send + 'static` since there is no writer thread. However, keeping them doesn't hurt and avoids changing all callers. You may relax them later.

Replace the current `execute_mode` function (lines 1146-1327) with:

```rust
pub fn execute_mode<M, C, F>(
    tasks: Vec<RegionTask>,
    general: &GeneralOptions,
    sample_paths: Arc<Vec<PathBuf>>,
    collector: C,
    thread_count: usize,
    mode: &M,
    metadata: Arc<M::Metadata>,
    header_builder: F,
    group_count: usize,
) -> Result<C::Output>
where
    M: PipelineMode,
    C: RowCollector + Send + 'static,
    F: FnOnce(Vec<usize>) -> Result<MatrixHeader> + Send + 'static,
{
    let task_count = tasks.len();

    // ── Phase 1: Build WorkItems with compute sort keys ──────────────
    let work_items: Vec<WorkItem> = tasks
        .into_iter()
        .map(|task| {
            let plan = mode.plan_for(&task.record, metadata.as_ref());
            WorkItem {
                orig_idx: task.index,
                group_index: task.group_index,
                record: task.record,
                query_start: plan.window_start(),
                query_end: plan.window_end(),
            }
        })
        .collect();

    if task_count == 0 {
        let header = header_builder(vec![0; group_count])?;
        return collector.finalize(header);
    }

    // ── Phase 2: Determine output strategy ───────────────────────────
    let already_sorted = input_order_is_compute_sorted(&work_items);
    let strategy = match general.sort_regions {
        SortRegions::Keep if already_sorted => OutputStrategy::StreamOrdered,
        SortRegions::No => OutputStrategy::StreamOrdered,
        SortRegions::Keep => OutputStrategy::InMemoryKeep,
        SortRegions::Ascend | SortRegions::Descend => OutputStrategy::InMemoryGroupBucket,
    };

    // ── Phase 3: Sort for I/O locality (skip if already sorted) ──────
    let mut work_items = work_items;
    if !already_sorted {
        work_items.sort_by(|a, b| {
            a.record.chrom.cmp(&b.record.chrom)
                .then(a.query_start.cmp(&b.query_start))
                .then(a.query_end.cmp(&b.query_end))
        });
    }

    // ── Phase 4: Open shared bigWig readers ──────────────────────────
    let shared_readers = Arc::new(
        sample_paths
            .iter()
            .map(|path| {
                SharedBigWigReader::open(path)
                    .map(Arc::new)
                    .with_context(|| format!("Failed to open bigWig file '{}'", path.display()))
            })
            .collect::<Result<Vec<_>>>()?,
    );

    // ── Phase 5: Create coalesced batches ────────────────────────────
    let coalesce_gap = estimate_coalesce_gap(&work_items);
    let coalesce_strategy = if coalesce_gap >= COALESCE_CLAMP_MAX {
        CoalesceStrategy::NoCoalesce
    } else {
        CoalesceStrategy::Coalesce(coalesce_gap)
    };
    let batches = create_batches(work_items, &coalesce_strategy);

    // ── Phase 6: Build thread pool ───────────────────────────────────
    let pool = ThreadPoolBuilder::new()
        .num_threads(thread_count)
        .build()
        .context("Failed to build rayon thread pool")?;

    // ── Phase 7: Chunk-parallel compute + output dispatch ────────────
    let chunk_size = std::cmp::max(256, batches.len() / (thread_count * 4));
    let metadata_ref = metadata.as_ref();

    match strategy {
        OutputStrategy::StreamOrdered => {
            let mut collector = collector;
            let mut group_counts = vec![0usize; group_count];

            for chunk in batches.chunks_vec(chunk_size) {
                let results: Vec<Result<Vec<BatchResult>>> = pool.install(|| {
                    chunk
                        .into_par_iter()
                        .map_init(
                            || WorkerSamples::from_shared(
                                Arc::clone(&sample_paths),
                                Arc::clone(&shared_readers),
                            ),
                            |ws, batch| {
                                let samples = ws.samples()?;
                                process_batch(samples.as_mut_slice(), batch, mode, general, metadata_ref)
                            },
                        )
                        .collect()
                });

                for batch_result in results {
                    for (_, group_index, row_opt) in batch_result? {
                        if let Some(row) = row_opt {
                            collector.on_row(row)?;
                            group_counts[group_index] += 1;
                        }
                    }
                }
            }

            let header = header_builder(group_counts)?;
            collector.finalize(header)
        }

        OutputStrategy::InMemoryKeep => {
            let mut all_rows: Vec<(usize, usize, Option<MatrixRow>)> =
                Vec::with_capacity(task_count);

            for chunk in batches.chunks_vec(chunk_size) {
                let results: Vec<Result<Vec<BatchResult>>> = pool.install(|| {
                    chunk
                        .into_par_iter()
                        .map_init(
                            || WorkerSamples::from_shared(
                                Arc::clone(&sample_paths),
                                Arc::clone(&shared_readers),
                            ),
                            |ws, batch| {
                                let samples = ws.samples()?;
                                process_batch(samples.as_mut_slice(), batch, mode, general, metadata_ref)
                            },
                        )
                        .collect()
                });

                for batch_result in results {
                    all_rows.extend(batch_result?);
                }
            }

            // Restore original input order
            all_rows.sort_by_key(|(orig_idx, _, _)| *orig_idx);

            let mut group_counts = vec![0usize; group_count];
            let mut collector = collector;
            for (_, group_index, row_opt) in all_rows {
                if let Some(row) = row_opt {
                    collector.on_row(row)?;
                    group_counts[group_index] += 1;
                }
            }

            let header = header_builder(group_counts)?;
            collector.finalize(header)
        }

        OutputStrategy::InMemoryGroupBucket => {
            let total_bins = mode.total_bins(metadata_ref);
            let sample_count = sample_paths.len();
            let mut bucket_collector = GroupBucketCollector::new(
                group_count,
                sample_count,
                total_bins,
            );

            for chunk in batches.chunks_vec(chunk_size) {
                let results: Vec<Result<Vec<BatchResult>>> = pool.install(|| {
                    chunk
                        .into_par_iter()
                        .map_init(
                            || WorkerSamples::from_shared(
                                Arc::clone(&sample_paths),
                                Arc::clone(&shared_readers),
                            ),
                            |ws, batch| {
                                let samples = ws.samples()?;
                                process_batch(samples.as_mut_slice(), batch, mode, general, metadata_ref)
                            },
                        )
                        .collect()
                });

                for batch_result in results {
                    for (_, group_index, row_opt) in batch_result? {
                        if let Some(row) = row_opt {
                            bucket_collector.on_row_with_group(group_index, row)?;
                        }
                    }
                }
            }

            let matrix_data = bucket_collector.finalize_grouped(header_builder)?;
            // Caller (scale_regions/reference_point) handles sort_groups + write
            // We need to return this through the collector interface.
            // For this path, C is always InMemoryCollector.
            // We pass all rows through collector in group order.
            let mut collector = collector;
            let header = matrix_data.header;
            for row in matrix_data.rows {
                collector.on_row(row)?;
            }
            collector.finalize(header)
        }
    }
}
```

**Important implementation note:** `Vec<CoalescedBatch>` does not have a `chunks_vec` method. You need to implement chunked iteration. Use:

```rust
fn into_chunks<T>(items: Vec<T>, chunk_size: usize) -> Vec<Vec<T>> {
    let mut chunks = Vec::new();
    let mut iter = items.into_iter();
    loop {
        let chunk: Vec<T> = iter.by_ref().take(chunk_size).collect();
        if chunk.is_empty() {
            break;
        }
        chunks.push(chunk);
    }
    chunks
```

```rust
    &mut self,
    chrom_ix: u32,
    start: u32,
    end: u32,

    self.blocks_buf.clear();
    self.remaining_buf.clear();
    self.remaining_buf.push_front(self.shared.cir_tree_root);

    while let Some(node_offset) = self.remaining_buf.pop_front() {
        let node = if let Some(cached) = self.cir_node_cache.get(&node_offset) {

                    size: item.data_size,
```

New body:
```rust
fn read_and_decompress<'a>(
    file: &File,
    offset: u64,
    size: u64,
    read_buf: &mut Vec<u8>,
    decode_buf: &'a mut Vec<u8>,
) -> io::Result<&'a [u8]> {
    if size == 0 {
        return Ok(&[]);
    }

    let buf_len = size as usize;
    if buf_len > read_buf.len() {
        read_buf.resize(buf_len, 0);
    }
    file.read_exact_at(&mut read_buf[..buf_len], offset)?;

    let block = &read_buf[..buf_len];
    if block.is_empty() {
        return Ok(&[]);
    }

    if block[0] == 0x78 {
        // zlib compressed
        decode_buf.clear();
        let capacity_hint = buf_len * 4;
        if decode_buf.capacity() < capacity_hint {
            decode_buf.reserve(capacity_hint - decode_buf.capacity());
        }
        let mut decoder = flate2::Decompress::new(true);
        decoder
            .decompress_vec(block, decode_buf, flate2::FlushDecompress::Finish)
            .map_err(|e| io::Error::new(io::ErrorKind::InvalidData, e.to_string()))?;
        Ok(decode_buf.as_slice())
    } else {
        // Uncompressed — data is in read_buf
        Ok(&read_buf[..buf_len])
    }
}
```

Key difference: `decode_buf` is reused across calls (only `clear()`, no realloc unless capacity insufficient). No more `copy_from_slice` back into `work_buf`.

- [ ] **Step 3: Update `get_or_cache_block` call site**

```rust
fn get_or_cache_block(&mut self, offset: u64, size: u64) -> io::Result<Arc<[u8]>> {
    let key = (offset, size);
    if let Some(data) = self.block_cache.get(&key) {
        return Ok(Arc::clone(data));
    }

    let raw = read_and_decompress(
        &self.shared.file,
        offset,
        size,
        &mut self.work_buf,
        &mut self.decode_buf,
    )?;
    let data: Arc<[u8]> = Arc::from(raw);

    if !data.is_empty() {
        if self.block_cache.len() >= MAX_BLOCK_CACHE_ENTRIES {
            self.block_cache.clear();
        }
        self.block_cache.insert(key, Arc::clone(&data));
    }

    Ok(data)
}
```
